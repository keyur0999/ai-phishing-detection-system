SCHEMA INSPECTOR

Relational SQL Database Architecture

SQLite: phishguard.db
users TABLE
  • id INT PK AUTO
  • username TEXT UNIQUE
  • email TEXT UNIQUE
  • password_hash TEXT (PBKDF2)
  • last_login_at TIMESTAMP
  • login_count INTEGER
user_logins ★ AUDIT
  • id INT PK AUTO
  • user_id INT FK (users)
  • username TEXT
  • ip_address TEXT
  • user_agent TEXT
  • login_time TIMESTAMP
  • status TEXT (success/failed)
scans TABLE
  • id INT PK AUTO
  • user_id INT FK
  • scan_type TEXT (url/email/qr)
  • input_data TEXT
  • verdict TEXT (safe/phish)
  • risk_score INT (0-100)
reports TABLE
  • id INT PK AUTO
  • scan_id INT FK
  • reason TEXT
  • status TEXT
  • created_at TIMESTAMP
