Relational SQL Database Architecture (SQLite)

Active tables, foreign key constraints, and storage layout in phishguard.db

SQLite 3.x • WAL Mode
users TABLE
  • id INT PK AUTO
  • username TEXT UNIQUE
  • email TEXT UNIQUE
  • password_hash TEXT (PBKDF2)
  • last_login_at TIMESTAMP
  • login_count INTEGER
  • created_at TIMESTAMP
user_logins AUDIT
  • id INT PK AUTO
  • user_id INT FK (users)
  • username TEXT
  • ip_address TEXT
  • user_agent TEXT
  • login_time TIMESTAMP
  • status TEXT (success/failed)
scans TABLE
  • id INT PK AUTO
  • user_id INT FK
  • scan_type TEXT (url/email/qr)
  • input_data TEXT
  • verdict TEXT (safe/phish)
  • risk_score INT (0-100)
  • reasons JSON TEXT
  • created_at TIMESTAMP
reports TABLE
  • id INT PK AUTO
  • scan_id INT FK
  • user_id INT FK
  • reason TEXT
  • status TEXT (pending/resolved)
  • created_at TIMESTAMP
blocklist TABLE
  • id INT PK AUTO
  • domain TEXT UNIQUE
  • reason TEXT
  • added_at TIMESTAMP
threat_indicators TABLE
  • id INT PK AUTO
  • indicator TEXT UNIQUE
  • category TEXT (url/email)
  • weight INTEGER
  • added_at TIMESTAMP
